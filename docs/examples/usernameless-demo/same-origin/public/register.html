1. Register a discoverable passkey

The page asks the server for PublicKeyCredentialCreationOptions configured with residentKey: required and userVerification: required. The authenticator stores the user handle locally, which is what makes the later sign-in possible without a username.

The username field below is part of this registration step only. Once the passkey is enrolled, the sign-in page does not need it any more.
