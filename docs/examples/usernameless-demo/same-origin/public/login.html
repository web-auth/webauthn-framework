2. Sign in without a username

Server-side, the assertion options carry an empty allowCredentials list. Browser-side, the page calls navigator.credentials.get({ mediation: 'conditional', publicKey }) so the user agent surfaces a passkey picker as autofill suggestions on the (visually empty) username input. Picking a passkey triggers the assertion.

If your browser does not support Conditional UI, click the Sign in manually button below to fall back to a modal passkey picker.

Output

Conditional UI armed. Focus the username field to surface the passkey picker, or click "Sign in manually".
