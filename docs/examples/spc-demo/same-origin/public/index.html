Secure Payment Confirmation — minimal demo

This demo runs the two W3C Secure Payment Confirmation ceremonies end-to-end against a relying party powered by web-auth/webauthn-lib:

  1. Register a credential with the payment: { isPayment: true } extension via navigator.credentials.create().
  2. Authenticate a payment with the Payment Request API: new PaymentRequest([{ supportedMethods: 'secure-payment-confirmation', data: {…} }]).show(). The relying party server validates the signed clientDataJSON.payment via PaymentClientDataCollector.

1. Register a credential 2. Pay with SPC

Browser support: SPC is available in Chromium-based browsers (Chrome, Edge, Opera) on platforms with a built-in user-verifying authenticator. On other browsers the checkout page will report that PaymentRequest is not implemented.
