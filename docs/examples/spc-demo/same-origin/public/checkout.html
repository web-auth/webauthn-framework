2. Authenticate a payment (Merchant origin)

The merchant page calls new PaymentRequest([{ supportedMethods: 'secure-payment-confirmation', data: {…} }]).show(). The browser shows its own SPC dialog (amount, payee, instrument). The user confirms with the platform authenticator. PaymentResponse.details is then a WebAuthn-shaped credential whose clientDataJSON.payment is what the relying party server validates.

Output

Submit the form to start an SPC payment.
