FakeMerchant — checkout

A separate origin from FakeBank. The checkout page initiates the SPC payment via PaymentRequest, then forwards the resulting WebAuthn artefacts to FakeBank's ACS at http://localhost:8001/api/acs/verify (cross-origin POST, CORS-enabled on the bank). The bank's ACS re-verifies the assertion against the credential's public key it stored at enrolment and returns a 3DS-style ARes payload (transStatus, eci, CAVV).

Make sure you have first enrolled a credential at FakeBank.
