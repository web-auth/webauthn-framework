Vault — encrypt anything, decrypt on demand

Authenticate with the credential you registered earlier. The page derives two keys from the PRF outputs and keeps them in memory for this tab — never persisted, never sent:

  • an AES-GCM key from prf.results.first (HKDF info "webauthn-prf-demo:aes") — used to encrypt and decrypt item plaintexts;
  • an HMAC-SHA256 key from prf.results.second (HKDF info "webauthn-prf-demo:hmac") — used to authenticate the label + iv + ciphertext tuple of every item so the page can detect if the server (or anyone with database access) silently changed a label or swapped two ciphertexts.

Every item you add is encrypted and signed client-side before leaving the page. Reload the tab → both keys are gone, you have to re-authenticate.
