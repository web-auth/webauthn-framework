Basic WebAuthn Demo

Minimal end-to-end example of a username-based passkey login in pure PHP, using web-auth/webauthn-lib. The whole demo runs on the built-in PHP web server, no database required.

1. Register a passkey

Create a brand-new account secured by a passkey.

2. Sign in

Authenticate as an existing account using one of its registered passkeys.

3. Manage passkeys

Once signed in: list registered credentials, add another passkey (e.g. a second device), rename or delete.

What this demo demonstrates

  • The four endpoints of a WebAuthn relying party: /api/register/options, /api/register/verify, /api/login/options, /api/login/verify.
  • What to actually store after a successful registration (the CredentialRecord blob plus a user binding).
  • How to update the stored record after every successful sign-in (counter, backup flags).
  • How to enrol additional passkeys on an existing account.
  • Why the relying party MUST refuse to delete the last passkey of an account.

What this demo deliberately leaves out

  • A real database. Credentials live in a JSON file under var/.
  • Account recovery. Lose every registered passkey, lose the account.
  • Account email verification, password fallback, rate limiting, CSRF protection, ...
  • Production-grade attestation. The demo accepts the none attestation format only.
